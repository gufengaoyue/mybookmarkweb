# Web 书签导航（web_api）

一个跑在本机的**个人书签导航页**：左侧树形分组、右侧书签卡片/列表、支持全库搜索、拖拽整理，并通过**坚果云 WebDAV** 把书签、分组和图标同步到云端。

后端是 Flask（单文件 `server.py`）＋ 纯前端静态页（`static/`），不依赖数据库，所有数据都是 `static/api/` 下的 JSON 文件与图标目录。

```
Flask (3000) ── 静态页 + REST API ── static/api/links.json / groups.json / icon/
                     │
                     └── webdav_sync.py ── 坚果云 WebDAV ── bookmark_api/{links.json, groups.json, icons.zip}
```

---

## 功能特性

- **树形分组**：分组支持 `父/子` 层级（如 `系统编程/Python`），可折叠展开、新建空分组、重命名、删除；删除非空分组时书签自动转入「未分组」。
- **点父分组看全部**：选中父分组时，卡片区显示该分组**及其所有子分组**的书签，侧栏计数也是累计值。
- **两种浏览样式**：卡片 / 列表一键切换（记忆在 localStorage）；搜索命中时固定用列表（分组 / 添加日期 / 名称 / 图标+链接）。
- **全库搜索**：搜索范围是全部书签（不限当前分组），匹配名称或网址；点任一分组自动退出搜索。
- **拖拽整理**：同组拖动改顺序（自定义拖拽影像 + FLIP 让位动画），拖到左侧分组上直接改所属分组。
- **新增收藏**：弹窗支持自动探测网站图标、选择已打开的浏览器标签页、选择/新建分组；探测的图标不落盘，关窗即清理。
- **世界时间**：右上角浮窗显示多时区时间，可隐藏，不遮挡卡片。
- **云同步**：立即同步 / 上传 / 下载 / 全量覆盖，增量比较 + 单次打包传图标 + 限流保护（详见[坚果云同步](#坚果云同步配置)）。
- **自动备份**：每次写盘前备份 `links.json`；下载覆盖前还会备份图标目录。

## 快速开始

### 1. 环境要求

- Python 3.9 及以上（开发环境为 3.11）
- 现代浏览器（Chrome / Edge）
- 可选：坚果云账号（不用云同步则不需要）

### 2. 安装依赖

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
```

`requirements.txt`：

```
Flask>=3.0,<4.0
flask-cors>=4.0,<5.0
```

### 3. 启动

```bash
python server.py
```

浏览器打开 [http://127.0.0.1:3000/](http://127.0.0.1:3000/)。

默认只监听本机回环地址 `127.0.0.1:3000`，**只有这台电脑能访问**，同一 WiFi / 局域网里的手机、同事电脑都连不上（见[安全提示](#安全提示)）。

Windows 想无窗口常驻，可以：

```powershell
Start-Process -FilePath "C:\Python311\pythonw.exe" -ArgumentList "server.py" `
  -WorkingDirectory "D:\path\to\web_api"
```

### 4. 第一次使用

`links.json`、`groups.json`、`icon/` 都不入库，首次运行会生成空的 `links.json`。可以：

- 页面右上「新增收藏」逐条添加；或
- 从浏览器导出的收藏夹 HTML 批量导入（字段为 `{id,name,url,icon,group}`，见[数据格式](#数据格式)）；或
- 配置坚果云后点「下载到本地」，从云端恢复一份完整数据。

## 坚果云同步配置

同步走**坚果云 WebDAV**，只依赖 Python 标准库，不需要额外服务。

### 1. 拿到 WebDAV 账号密码

1. 注册/登录 [坚果云](https://www.jianguoyun.com/)，进入网页端。
2. 右上角账户信息 → **安全选项** → **添加应用**（第三方应用管理）。
3. 生成一条应用密码，复制备用。

> 注意：这里用的是**应用密码**，不是你的登录密码。应用密码可以随时在坚果云后台吊销。

### 2. 在页面里登录

页面右上「云同步」→ 面板中输入：

| 字段     | 内容                               |
| -------- | ---------------------------------- |
| 邮箱     | 坚果云账号邮箱                     |
| 应用密码 | 上一步生成的应用密码（非登录密码） |

点「登录并连接」，凭据保存在本机 `sync_config.json`（密码以 base64 存储，**不入库**）。面板状态栏会显示已连接账号、本地/云端收藏数量、上次同步时间。

### 3. 云端目录结构

首次上传时自动创建，无需手工建目录：

```
坚果云/我的空间/bookmark_api/
├── links.json      # 书签（与本地同构）
├── groups.json     # 分组注册表（含空分组，删除会传播）
└── icons.zip       # 全部图标打包（一次 PUT 传完，避免几百次请求）
```

### 4. 四种操作语义（重要，别用反）

| 操作                 | 方向         | 比较方式                                             | 典型场景                       |
| -------------------- | ------------ | ---------------------------------------------------- | ------------------------------ |
| **立即同步**   | 双向         | 条目级合并 + 删除传播 + 冲突逐条选择                 | 两台机器都改过，想把两边合并   |
| **上传到云端** | 本地 → 云端 | 只传有差异的部分（**本地删除会推到云端**）     | 本机是唯一编辑端，改完就推     |
| **下载到本地** | 云端 → 本地 | 只拉有差异的部分（**本地删掉的会从云端恢复**） | 新机器初始化、误删后恢复       |
| **覆盖云端**   | 本地 → 云端 | 不做比较，links/groups/icons 整份替换                | 手工换过图标、怀疑差异判断漏了 |
| **覆盖本地**   | 云端 → 本地 | 不做比较，整份替换（覆盖前自动备份本地）             | 本地数据乱了，回到云端快照     |

一句话记忆：**上传 = 以本地为准（会删云端）；下载 = 以云端为准（会补回本地）**。

### 5. 增量是怎么判断的

- **书签条目**：按 `id` 对齐，比较多字段签名（名称、网址、图标、分组），只有签名变了才传。
- **图标**：全部图标打成**一个** `icons.zip`，一次 PUT 上传；下载时解包覆盖本地。
- **图标指纹** = 文件数 + 总字节 + **按内容算的 sha256 汇总**。所以即使你替换的图标大小相同、时间戳也没变，只要内容变了就会被发现（这是早期“换了图标却不生效”的根因修复）。
- **分组名单**：`groups.json` 单独一个小文件同步，空分组也能带过去，删除也会传播。

### 6. 限流与自我保护

坚果云 WebDAV 有请求频率限制（触发后返回 `503 Too many requests`）。程序内置：

- 任意两次请求之间至少间隔 `0.5s`；
- 对 `429 / 502 / 503 / 504` 自动重试（最多 5 次，指数退避）；
- 一旦被判为限流，进入 **10 分钟冷却**，期间前端会提示“约 X 分钟后可再次点击”；
- 上传走后台线程，前端轮询 `/api/sync/progress` 显示进度，避免长请求超时。

通常一轮全量同步只有 3 个请求（links、groups、icons.zip），不会因为图标多而被限流。

### 7. 本地文件与备份

| 文件                           | 内容                                    | 是否入库             |
| ------------------------------ | --------------------------------------- | -------------------- |
| `sync_config.json`           | `{email, password(base64), saved_at}` | 否（`.gitignore`） |
| `.sync_state.json`           | 本地/云端文件哈希、ETag、上次收藏数缓存 | 否                   |
| `backups/links_auto_*.json`  | 每次写盘前的自动快照，保留最近 20 份    | 否                   |
| `backups/图标目录备份_*.zip` | 「覆盖本地」前的图标整包备份            | 否                   |

「退出登录并清除凭据」会删除 `sync_config.json`，云端文件不受影响。

> 流量提示：打开同步面板只做 `HEAD` 判断 ETag / Last-Modified，云端计数走本地缓存，不会产生文件正文流量。

## 数据格式

### `static/api/links.json`

```json
[
  {
    "id": 1747031791270,
    "name": "GitHub",
    "url": "https://github.com/",
    "icon": "static/api/icon/fav_5d41402abc4b.png",
    "group": "系统编程/Git"
  }
]
```

- `id`：毫秒时间戳（新建时生成，同时作为列表里的「添加日期」）。
- `group`：分组路径，用 `/` 表示层级；空值或缺失按「首页」处理。
- `icon`：可以是本地路径，也可以是 http 链接（保存时会下载到本地 `static/api/icon/`）。

### `static/api/groups.json`

```json
["首页", "系统编程", "系统编程/Python", "未分组", "书法"]
```

只存分组名，用来让**空分组**也能显示、可重命名。`首页` 与 `未分组` 是保留分组：`首页` 不可重命名/删除，`未分组` 可重命名不可删除。

## 常见问题

**书签名称为空 / 只显示一半？**
从飞书、微信复制标题会带入零宽格式字符（U+202B、U+200B、U+FEFF 等），宽度为 0，截断后看起来是空白。服务端 `clean_text()` 会在写盘前清理，前端显示时也会兜底清洗；历史脏数据重启后重新保存即修复。

**换了图标，云端不生效？**
增量判断已按文件内容算哈希，正常上传即可发现。若确认没生效，点「覆盖云端」强制整份上传。

**下载后，我本地删掉的书签又回来了？**
这是正确行为：下载语义是“以云端为准”。要删除云端记录请用「上传到云端」。

**出现 `503 Too many requests`**
触发了坚果云限流。等提示的冷却时间（约 10 分钟）后重试，程序会自动续传未完成的图标包。

**页面空白 / 读不到书签**
确认 `static/api/links.json` 是合法 UTF-8 JSON（文件不能是 GBK，也不能有 BOM）。程序读写在 `save_data()` 中已统一 UTF-8 + 原子写，异常时会保留 `backups/` 里的上一份快照。

**端口被占用**
`server.py` 末尾固定 `port = 3000`，改一行即可；前端 `func.js` 里的 `server` / `groupServer` 变量也指向 3000，需要一起改。

**手机或另一台电脑打不开页面？**
默认只监听 `127.0.0.1`，本来就只允许本机访问。确有需要时按[安全提示](#安全提示)里的 `WEB_API_HOST=0.0.0.0` 临时放开，同时留意同网段的任何人都能改你的书签。

**图标不显示**
`static/api/icon/` 被 `.gitignore` 忽略，从 GitHub 克隆下来图标是空的，需要通过云同步「下载到本地」或重新添加书签来补。

## 安全提示

- 这是**单用户、无鉴权**的本地工具，默认**只监听本机回环地址 `127.0.0.1:3000`**：局域网里的其他设备（手机、同事电脑）无法访问，也读不到、改不了你的书签数据。
- 确实需要手机/平板临时访问时，再显式放开：

  ```powershell
  # Windows PowerShell：仅当前这次启动生效，关掉窗口即恢复默认
  $env:WEB_API_HOST = "0.0.0.0"; python server.py
  ```

  ```bash
  # macOS / Linux
  WEB_API_HOST=0.0.0.0 python server.py
  ```

  放开后同网段设备即可访问 `http://<本机IP>:3000/`，此时**任何人拿到这个地址都能增删你的书签**，用完请改回默认（或关闭程序）。**任何时候都不要把它直接暴露到公网**；如需外网访问，请套一层带认证的反向代理（Nginx Basic Auth / Tailscale 等）。
- `sync_config.json`（坚果云应用密码）、`.sync_state.json`、`backups/`、`links.json`、`groups.json`、`icon/` 全部在 `.gitignore` 中，**不要把它们提交到公开仓库**。
- 上传/下载/覆盖都会改写数据，写盘前自动备份；重大操作前建议再点一次「本地备份」。
